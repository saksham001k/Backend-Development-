Exam01 My Notes

Add, display and delete notes stored in MongoDB. EJS renders the pages, title and content are validated on the server, and CSS provides the optional interface enhancement.

  • Required features: all four note fields, empty state, add form, validation, database insertion, redirect and deletion by ObjectId are implemented.
  • Submission: source, templates, CSS, run instructions and an application screenshot are included.
  • Viva topics: Express routes, form parsing, EJS, MongoClient, find/toArray, insertOne, deleteOne, ObjectId, status codes and persistence.
  • Scope: PostgreSQL, login and a separate REST API are not required for Exam01. CSS is the selected optional enhancement.
