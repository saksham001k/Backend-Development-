# Theory Task 5: LocalStorage, SessionStorage and JSON

## Objective

To understand browser storage and create a Notes application that stores JavaScript objects using JSON.

## Features

- Add notes
- Display saved notes on page load
- Edit and delete notes
- Search notes
- Store `id`, `text`, `createdAt` and `updatedAt`
- Preserve data after page refresh using localStorage
- Escape user text before displaying it

## Concepts Used

- `localStorage.setItem()` and `getItem()`
- `JSON.stringify()` and `JSON.parse()`
- DOM manipulation and event handling

## Result

A working Notes application with browser-based persistent storage was created successfully.
