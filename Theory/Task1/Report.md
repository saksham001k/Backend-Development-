# Theory Task 1: Node.js and Express Environment

## Objective

To set up Node.js and Express and create routes that return text, HTML, JSON and dynamic EJS pages.

## Work Completed

- Node.js project initialized with NPM
- Express server configured
- Home and student routes created
- Student data rendered using EJS templates
- Project dependencies stored in `package.json`

## Run

```bash
cd NODE-JS
npm install
node server.js
```

Open `http://localhost:3000` in the browser.

## Result

The Node.js and Express development environment was configured and tested successfully.
