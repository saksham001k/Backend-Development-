# Theory Task 4: Sessions, Cookies and Query Strings

## Objective

To understand how a server maintains state using sessions and cookies and how query parameters are read from a URL.

## Implemented Routes

- `/login`, `/profile`, `/logout` for sessions
- `/setcookie`, `/getcookie`, `/deletecookie` for cookies
- `/welcome?user=Saksham&role=student` for query strings

## Run

```bash
npm install
node app.js
```

## Result

Session creation, session destruction, cookie handling and query-string processing were implemented successfully.
