# Experiment 7 & 8: ES6, DOM Manipulation and Event Handling

**Name:** Saksham Katiyar  
**SAP ID:** 590015169  
**Date:** 27 October 2026

## Objective

To demonstrate ES6 features and use the DOM and events to build an interactive To-Do list.

## Procedure

1. Created a form, input and task list in HTML.
2. Used a Task class and an array to store tasks in memory.
3. Used arrow functions, spread and destructuring while adding and rendering tasks.
4. Created task rows using DOM methods and assigned titles with `textContent`.
5. Handled form submission with `addEventListener()` and `preventDefault()`.
6. Used event delegation to mark tasks complete/incomplete and delete them.
7. Added a module demonstrating default parameters, rest, classes, object literals, promises and async/await.

## Verification

- The ES6 module ran in Node.js and produced the expected greetings, array output, module calculation and asynchronous messages.
- Browser checks passed for Add, Enter submission, blank-title rejection, completion toggle and deletion.
- Verified literal text rendering, module loading, responsive layout and reset after refresh. No page script errors were recorded.

## Result

The source implements adding, toggling and deleting tasks without a page reload. Module output demonstrates modern JavaScript features. Refreshing the page clears this in-memory list; SQLite persistence belongs to Experiment 15.
