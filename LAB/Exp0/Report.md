# Experiment 0: Git Basics

## Objective

To understand the basic Git workflow used to track and manage source code.

## Tools Used

- Git
- GitHub
- Visual Studio Code
- Terminal

## Commands Practised

```bash
git init
git status
git add .
git commit -m "Initial commit"
git branch
git checkout -b feature-demo
git merge feature-demo
git stash
git stash pop
git remote -v
git log --oneline
```

## Procedure

1. Created a sample text file and initialized a Git repository.
2. Checked the status of tracked and untracked files.
3. Added and committed the file.
4. Created a separate branch and made a small change.
5. Merged the branch into the main branch.
6. Practised saving unfinished changes with Git stash.
7. Checked the remote repository and commit history.

## Result

The basic Git workflow, branching, merging, stashing and remote repository commands were understood successfully.

## Conclusion

Git makes it easier to maintain versions of a project and collaborate without losing previous work.
