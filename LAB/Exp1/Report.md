# Experiment 1: Create a Web Page with HTML5 Elements

## Course Outcome

**CO2:** Create and build web pages and applications.

## Objective

The objective of this experiment is to create a well-structured HTML5 webpage using different HTML5 elements and understand their purpose and usage.

The experiment includes:

* Semantic HTML5 elements
* Text formatting elements
* Ordered, unordered, and description lists
* Tables
* Forms and different input types
* Multimedia elements
* Interactive HTML5 elements

## Requirements / Tools

* Visual Studio Code
* Web Browser
* HTML5
* Browser Developer Tools

## Procedure

1. Created an `index.html` file.
2. Added the basic HTML5 document structure.
3. Used semantic elements such as:

   * `header`
   * `nav`
   * `main`
   * `section`
   * `article`
   * `footer`
4. Added different text formatting elements.
5. Implemented ordered, unordered, and description lists.
6. Created an HTML table.
7. Added a form using different HTML5 input types.
8. Included multimedia and interactive HTML5 elements.
9. Tested the webpage in a web browser.

## Implementation

The webpage was developed using HTML5 and demonstrates the use of multiple HTML elements within a single structured webpage.

The implementation is available in:

`index.html`

## Result

A webpage using different HTML5 elements was created successfully and tested in the browser.

## Conclusion

This experiment provided practical understanding of HTML5 page structure and commonly used HTML5 elements. It also demonstrated how semantic tags, forms, tables, lists, multimedia, and interactive elements can be combined to build a structured webpage.
