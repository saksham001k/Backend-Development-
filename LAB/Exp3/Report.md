# Experiment 3: Responsive Web Page with HTML and CSS

## Objective

To create a webpage that adjusts properly on desktop, tablet and mobile screens.

## Tools Used

- HTML5
- CSS3
- Browser Developer Tools

## Procedure

1. Added the viewport meta tag.
2. Created a responsive navigation bar.
3. Used Flexbox for the hero section.
4. Used CSS Grid for four content cards.
5. Added tablet and mobile breakpoints using media queries.
6. Used a responsive image and added a dark-mode media query.
7. Tested the layout at different browser widths.

## Result

The webpage changes from four columns to two columns and finally one column according to the available screen width.

## Conclusion

Flexible layouts, responsive images and media queries help one webpage work correctly on different devices.
