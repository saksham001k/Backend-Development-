# Experiment 2: Types of Cascading Style Sheets

## Objective

To implement inline, internal and external CSS and practise selectors, Flexbox, Grid, transitions and animations.

## Tools Used

- HTML5
- CSS3
- Visual Studio Code
- Web Browser

## Procedure

1. Created an HTML page and linked an external stylesheet.
2. Added examples of inline and internal CSS.
3. Applied element, class, ID and attribute selectors.
4. Created layouts using Flexbox and CSS Grid.
5. Added a hover transition and a simple keyframe animation.
6. Opened the page in a browser and checked the output.

## Files

- `index.html`
- `style.css`

## Result

A webpage demonstrating the main types and commonly used features of CSS was created successfully.

## Conclusion

External CSS is useful for reusable styling, while internal and inline CSS can be used for page-specific and element-specific changes.
