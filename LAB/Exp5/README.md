## Run

From the repository root:

```bash
cd LAB/Exp5
node script.js
node script2.js
node library.js
```

Open `index.html` in a browser and open its developer console to see the same output. On Mac Chrome, use Command + Option + J. No npm installation or database is needed.

## Files

- `script.js`: arrays, a student object and a greeting function.
- `script2.js`: uppercase, lowercase, split, and add/read/update examples.
- `library.js`: the PBL activity using `library`, `addBook(title, author)` and `findBook(title)`.
- `index.html`: browser integration.
- [Report](Report.md): objective, procedure and outcome.

Book titles are matched exactly, including letter case. A missing title returns `undefined`. Books exist only in memory and reset when the script runs again.
