# Experiment 4: Responsive Web Pages with Bootstrap and Tailwind CSS

## Objective

To create responsive webpages using Bootstrap components and Tailwind CSS utility classes.

## Tools Used

- HTML5
- Bootstrap 5
- Tailwind CSS
- Web Browser

## Procedure

1. Added Bootstrap and Tailwind through their CDN links.
2. Created responsive navigation bars.
3. Created hero sections and responsive card grids.
4. Used Bootstrap's 12-column grid system.
5. Recreated the layout using Tailwind utility classes.
6. Added responsive contact forms to both pages.
7. Tested both implementations at different screen sizes.

## Files

- `bootstrap.html`
- `tailwind.html`

## Result

Responsive webpages were created successfully using both Bootstrap and Tailwind CSS.

## Conclusion

Bootstrap provides ready-made components, while Tailwind provides utility classes that allow more direct control over the design.
